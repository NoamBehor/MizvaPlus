# מחיקת חשבון — מצוות פלוס

דוא״ל לפניות: noambehor@gmail.com

כדי למחוק את החשבון ואת הנתונים המשויכים אליו:

1. פתחו את מצוות פלוס.
2. התחברו.
3. היכנסו לפרופיל.
4. בחרו "מחיקת חשבון".
5. אשרו ב"מחק לצמיתות".

המחיקה מסירה מ-Supabase את משתמש האימות, את התקדמות המצוות, החידונים וההישגים, ואת דיווחי המניין שהגשתם. מיקום שנשמר עם הדיווח נמחק יחד איתו. אין איסוף מיקום ברקע.

אם אינכם מצליחים להיכנס לאפליקציה, שלחו בקשת מחיקה אל noambehor@gmail.com מאותה כתובת שבה נרשמתם.
